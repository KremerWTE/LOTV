Lily of the Valley
Social Services Platform

A multi-tenant SaaS coordination platform built on .NET 9 that connects people in need, donors, volunteers, and staff across diocese organizations — enabling service request routing, donation tracking, event management, and real-time impact reporting.

Frontend Views (Lotv.Web)

Role-based Blazor WASM views for all 5 user types. Route guards enforce access per role.

Submit Request

Multi-step form to submit a new service request with category, urgency, and description.

My Requests

List of all submitted requests with current status and timeline.

Status Tracking

Real-time status view: submitted → assigned → in-progress → fulfilled.

Profile

Personal profile, contact info, diocese affiliation, request history.

Register

Donor registration with diocese affiliation and communication preferences.

Monetary Donation

Donation form with Stripe checkout integration and amount selection.

Resource Donation

Log resource donations: type, quantity, condition, pickup/dropoff.

Receipt Download

Download PDF receipt for any contribution for tax purposes.

Contribution History

Full history of all monetary and resource donations with receipts.

My Impact

Personalized impact statement: how donations helped people in need.

Register

Volunteer registration with skills, availability, and service area.

Available Requests (Map)

Map + list view of requests available to accept in your service area.

Pending Assignments

Requests awaiting your accept/decline decision.

My Work Queue

Active assignments with details, notes, and completion form.

Completion Form

Mark fulfillment complete, add outcome notes, upload photos.

All Requests Dashboard

Full-screen table of all requests with filtering, sorting, and bulk actions.

Unassigned Queue

Priority list of requests not yet assigned to any volunteer or staff.

Kanban Board

Drag-and-drop board: Submitted → Assigned → In Progress → Fulfilled → Closed.

Request Detail

Full request view with timeline, notes, assignments, and escalation controls.

Workload View

Per-volunteer capacity and current assignment count for workload balancing.

Allocation Ledger

Track monetary and resource allocations tied to specific service requests.

User Management

Create, edit, deactivate users; assign roles (Staff, Volunteer, Donor, etc.).

Diocese Management

Add/edit dioceses used as organizational groupings for donors and requests.

System Configuration

Platform settings: escalation thresholds, notification templates, integrations.

Audit Log

Full system audit trail: who did what, when, with before/after values.

Impact & Distribution Dashboard

KPI cards, money flow chart, resource distribution, geographic map, activity timeline, category breakdown, and full allocation ledger.

Donation Tracking Dashboard

Donations segmented by person, diocese, city, channel (Online/Check/Cash/InKind), and amount band. Full donor ledger with drill-down.

Event Management Dashboard

Upcoming events, event detail, attendee management, check-in, silent auction tracking, RSVP, and revenue summary.

Email notifications are included. SMS is optional and subject to a Change Order if a custom provider is required. Real-time auction bidding via SignalR is excluded from this SOW but may be added as a Phase 7 enhancement.
